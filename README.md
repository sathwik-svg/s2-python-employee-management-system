# 👨‍💼 S2 Python Employee Management System

A web-based Employee Management System built with **Python and Streamlit**.  
This project provides a simple dashboard for managing employee records with CRUD-style operations.

## 🚀 Live Demo

https://s2-python-employee-management-system.onrender.com/

## 📌 Project Information

- **Project:** S2 Project 3
- **Language:** Python
- **Framework:** Streamlit
- **Data Processing:** Pandas
- **Deployment:** Render
- **Development Environment:** Ubuntu Server
- **Version Control:** Git + GitHub

## ✨ Features

### 📊 Dashboard
- Total employee count
- Number of departments
- Average salary
- Total payroll
- Employees by department chart

### ➕ Add Employee
Add new employee records with:

- Employee ID
- Full name
- Department
- Job role
- Email
- Annual salary
- Joining date

### 📋 View Employees
- View all employee records
- Search employees
- Search by name, department, role, or email

### ✏️ Edit Employee
Update existing employee information including:

- Name
- Department
- Role
- Email
- Salary
- Joining date

### 🗑️ Delete Employee
Remove employee records using a confirmation step.
